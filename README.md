# トマトタイマー（Windows）

このアプリは、[2163kogasachiko](https://github.com/2163kogasachiko) さんによる macOS 版 [トマトタイマー](https://github.com/2163kogasachiko/tomato-timer) を、同じ使い方で Windows から使えるようにしたものです。タイマーの動き、画面の構成、通知音は Mac 版に沿っています。Mac 版そのものの配布とソースは、作者のリポジトリを参照してください。

## 起動

Python 3 が必要です。初回の `run.bat` が仮想環境を作り、必要なパッケージを入れます。

```bat
run.bat
```

用意済みの仮想環境では、次でも起動できます。

```bat
.venv\Scripts\python.exe -m tomato_timer
```

## 操作

Mac 版と同じです。

- 作業、短い休憩、長い休憩の時間設定
- 作業と休憩の自動切り替え
- 作業開始、休憩開始、休憩終了の通知音を別々に選択
- トマト画像のドラッグでウィンドウを移動、サイズ変更
- フェーズ終了時の通知音と、画面右上の通知

Windows では、終了と最小化のボタンを右上に置いています。最小化するとタスクバーへしまいます。

## トマト画像

Mac 版の配布アプリには、Adobe Stock のトマト画像（アセットID: 577240549）が使われています。利用条件に従い、画像ファイルはこのフォルダには含めていません。

許諾済みの画像を使うときは、次のいずれかにしてください。

- このフォルダに `tomato-cutout.png` を置く
- 隣の `tomato-timer` フォルダに `tomato-cutout.png` を置く
- 環境変数 `TOMATO_IMAGE` に画像のパスを指定する

画像を指定すると、ウィンドウ、タスクバーアイコン、通知に使います。画像がないときは、図形で描いたトマトを表示します。

## 通知音

`sounds` フォルダの音声は、Mac 版のプロジェクト用に作られたオリジナル音です。「おもちゃ風マーチ」は、既存楽曲の録音や複製ではありません。

## バージョン

設定画面のバージョン表示は、対応する Mac 版の仕様に合わせて 2.9 です。
